# Segurança e uso responsável

Este projeto não deve ser usado para contornar autenticação, paywalls, CAPTCHAs, bloqueios, limites de acesso ou termos de serviço. Use somente fontes cuja coleta e redistribuição sejam autorizadas.

Não abra issues com tokens, cookies, URLs privadas ou dados pessoais. Para relatar uma vulnerabilidade, contate os mantenedores por um canal privado da organização.
